Game Time vs Productivity Analysis

Tableau | Data Visualization Case Study

Problem Statement

Excessive gaming can impact productivity, focus, stress, and overall well-being. This project aimed to analyze how different gaming durations influence productivity and performance metrics using interactive visual analytics.

Dataset

  • Daily gaming duration
  • Productivity levels
  • Stress and focus scores
  • Sleep-related indicators

Tools & Features Used

  • Tableau
  • Calculated Fields
  • Filters and Parameters
  • Interactive Dashboards
  • Visual Storytelling

Approach

  1. Prepared and structured the dataset for visualization
  2. Created calculated fields to derive performance metrics
  3. Designed comparative charts to analyze gaming duration impact
  4. Added filters for dynamic exploration
  5. Focused on clarity and insight-driven storytelling

Key Insights

  • Moderate gaming showed minimal impact on productivity
  • Extended gaming durations correlated with reduced focus
  • Higher stress levels were observed with excessive gaming time

Outcome

The Tableau dashboard effectively highlighted behavioral patterns and productivity trends, helping users understand how gaming habits can influence performance and well-being.
