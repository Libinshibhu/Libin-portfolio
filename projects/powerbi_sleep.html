Sleep Health & Lifestyle Analysis

Power BI Dashboard | Data Analysis Case Study

Problem Statement

Poor sleep quality is often influenced by lifestyle factors such as physical activity, stress, and daily habits. The goal of this project was to analyze how these variables impact sleep quality and duration.

Dataset

  • Sleep duration & quality
  • Stress levels
  • Physical activity & daily steps
  • Demographic attributes

Tools & Technologies

  • Power BI
  • Power Query
  • DAX

Approach

  1. Cleaned and transformed raw data using Power Query
  2. Created calculated measures using DAX
  3. Designed interactive dashboards with slicers
  4. Analyzed patterns across lifestyle variables

Key Insights

  • Higher activity levels correlated with better sleep quality
  • Increased stress showed reduced sleep duration
  • Consistent daily steps improved sleep stability

Outcome

The dashboard provided clear, actionable insights that could help individuals make informed lifestyle adjustments to improve sleep health.
